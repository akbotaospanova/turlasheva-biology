# Жасушаның құпия әлемі

9-сынып оқушыларына арналған биологиядан авторлық элективті курс: 34 сабақ, интерактивті 3D модельдер, ойындар мен тесттер.

Автор: Турлашева Алина Маратовна, биология пәнінің мұғалімі, №169 мектеп-лицей, Алматы.

Сайтты ашу үшін `index.html` файлын браузерде ашыңыз немесе GitHub Pages арқылы жариялаңыз.
